# 提示词模板（已验证）

以下两个模板来自真实成功任务（HACOO 南非购物指南系列图中英对照），可直接套用。使用时将【占位】部分替换为实际内容，并逐行枚举两部分的全部文字。**支持任意原文语言（含阿语/阿拉伯语）**。

## 通用要点
- `image_reference_url_list` 按 `[原图, 样式参考图(如有)]` 顺序传入。
- 原文半区的文字必须与用户原图逐字一致；若与真实图片有出入，以图片实际内容为准修正枚举内容。
- 目标语言默认中文；若用户指定其他语言，替换"中文翻译"表述及译文内容。
- **阿语原文**：原文半区必须保留阿语视觉（RTL 从右到左排版、阿语字母连写），提示词中明确写"完全保留原图阿语视觉与从右到左排版，不要改动阿语文字"，避免模型把阿语改写成中文或重排；中文译文区保持 LTR 左对齐。
- 提示词中的"英文"字样按实际原文语言替换为"阿语"/"阿拉伯语"。

## 版式一：左右对照（左原文 / 右译文）

画布建议 `width=2400, height=1500`。


## 真实案例参考（HACOO 系列，2026-10-26/27 完成）
- 左右版式封面成品：2590×1619，左英文原版 + 右浅灰中文对照。
- 上下版式封面成品：1448×2896，上英文原版 + 下中文翻译版。
- 常见失败与修复：第一次生成时上半部分英文被模型统一成中文 → 重写 prompt，逐行明确列出上下两部分全部文字并显式声明"上半部分必须是英文，下半部分必须是中文，不能混淆"后成功。
- 阿语场景（用户在样式参考图中使用过阿语+中文左右对照）：左右版式同样适用，原文半区保留阿语 RTL 视觉不动。
